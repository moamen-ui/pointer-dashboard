All three verified: pure vector (no embedded raster), **no baked text layers** (so nothing to
translate for Arabic), and legible on both light and dark grounds.

Known limitation: Lottie colors are baked into the JSON, so these do NOT follow a runtime
`--brand` override the way the previous inline SVGs did.

The hand-authored SVG versions are kept alongside as `*.svg` for reference.
